# 📊 Prediktion av kundbortfall med maskininlärning
Detta projekt är en end-to-end implementation av en maskininlärningslösning för att prediktera kundbortfall (churn). Arbetet genomfördes som en del av kursen *Projekt i Data Science* vid EC Utbildning.

Projektet omfattar databehandling, modellering, utvärdering och analys av flera klassificeringsmodeller.

---

## 🧠 Syfte
Syftet är att undersöka hur maskininlärning kan användas för att identifiera kunder med hög risk att lämna en tjänst. Fokus ligger på:

- att bygga en komplett ML‑pipeline  
- att jämföra flera modeller  
- att analysera styrkor och svagheter  
- att diskutera praktisk användbarhet
